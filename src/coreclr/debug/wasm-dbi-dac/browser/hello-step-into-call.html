hello-step-into-call smoke (browser)

Status: running...

Sets a managed breakpoint at BreakHere; on the first hit issues a step-into request which enters the callee StepIntoTarget (reported as a structured step-complete DBI event at method-enter). On that event the harness issues a step-out request, returning to the caller. Both breakpoint events and step-complete events are drained via the sidecar DAC.
