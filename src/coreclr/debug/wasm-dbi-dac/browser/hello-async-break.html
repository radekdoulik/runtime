    Demonstration of the full IDE-driven async-break flow over CDP. The page
    is a passive runtime host: it loads the CoreCLR runtime + sidecar
    (mscordbi/DAC) and exposes a small globalThis.__dbi facade.
    Orchestration is driven from the IDE/DBI side via CDP
    Debugger.pause / Debugger.resume plus
    Runtime.evaluate calls into the facade.
  

  

    Two ways to drive this page:
    
    
      
  • Load extension/ as an unpacked Chrome extension, open this page with ?wait-for-external-dbi=1, click the extension action icon.
    • 
      
  • Run the Playwright spec: ./run-smokes.sh.
    • 
    

    Both run the same 8-step orchestration. See extension/README.md.
