This page demonstrates the cooperative IDE async-break path. The page itself simulates the mscordbi role — it loads the runtime, starts a busy loop, then sends a cooperative async_break_request. The runtime checks the request flag at the next sequence point, halts cleanly, emits a structured DBI event, and waits for the structured continue. No external CDP client is involved.
